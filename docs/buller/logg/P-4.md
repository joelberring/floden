SegmentVariables, spegelpunkten och höjdfaktorerna (frekvensoberoende); per frekvens Fresnelzonsvikten med F·λ = λ/16

(ekv. 177, 179, 181 med F_Δτ = 1) och \|p̂_G\| (ekv. 182). ΔL₄ = 20·lg(\|p̂_SCR\|·∏∏\|p̂_G\|^(w′w′)).

Uppmätt tid: 5,4 ms per profil och 27 band (testfall 71, 2 + 1 marksegment).

## Så anropas funktionerna från kärnan (till P-S)

```python
from buller.nord2000 import delmodell4 as d4, delmodell7 as d7
from buller.nord2000.refraktion import atmosfar_ur_vader
from buller.nord2000.terrang import terranggeometri
from buller.nord2000.terrang_skarmar import valj_skarmkanter, tolka_terrang

atm = atmosfar_ur_vader(vader)
geo = terranggeometri(profil)
kanter = valj_skarmkanter(geo)                         # T₁ och formen W₁–T₁–W₂, räta strålar

# 1. Δℓ för T₁ (ekv. 301) till kroken hos P-T. I homogen atmosfär ska kroken få None.
_, stralar = d4.skarmeffekt_fritt_falt_db(frekvenser, profil, kanter.primar_form, atm)
dl1 = stralar.gangvagsskillnad_m if atm.har_refraktion else None
t = tolka_terrang(geo, kanter, frekvenser, atm.c_m_s,
                  gangvagsskillnad_t1_m=dl1, gangvagsskillnad_t2_m=..., gangvagsskillnad_t12_m=...)

# 2. Delmodell 4 när 4 in t.delmodeller (homogen atmosfär; annars BullerFel).
r4 = d4.skarm_en_kant(frekvenser, profil, t.primar_form, atm)        # F_s: koherens_spridningszon=...
r4.delta_l_db        # ΔL₄ per band (ekv. 188)
r4.markfaktor_pg     # p_G före 20·lg, till delmodell 7
r4.skarmeffekt_db    # 20·lg|p_SCR|;  r4.delta_l_db = r4.skarmeffekt_db + 20·lg(r4.markfaktor_pg)

# 3. Delmodell 7,1 och ⊕ (ekv. 332): ΔL₄ ⊕ ΔL_7,1.
i = t.primar.index
dl71 = d7.turbulensspridning_en_kant_db(frekvenser, geo.x_s_m, geo.z_s_m, geo.x_r_m, geo.z_r_m,
                                        float(geo.x_m[i]), float(geo.z_m[i]), atm.cv2, atm.ct2,
                                        atm.temperatur_luft_c, markfaktor_pg=r4.markfaktor_pg)
dl4_tot = np.array([d7.energisumma_db(a, b) for a, b in zip(r4.delta_l_db, dl71)])
```

- `profil` är `Terrangprofil`; `form` är `Skarmform` med index i `terranggeometri(profil).x_m`. Punkter mellan W₁ och T
  och mellan T och W₂ påverkar inte kilens vinklar (formen reduceras till tre punkter, 5.13.2) men ingår i bilaga G.
- Byggd skärm med känd absorption: `q_kilyta_kalla=√ρ_E`, `q_kilyta_mottagare=√ρ_E` (tal eller ett värde per band).
- ΔL₄ är relativt fritt fält på avståndet R_SR (ekv. 163). ΔL_d ska alltså räknas med R = R_SR även för skärmade
  banor. För ΔL_a (ekv. 287) säger metoden inget annat än "propagation path length R"; samma R_SR är det enda som är
  konsekvent med ekv. (163) och (329). **Öppen fråga 4 i B4-uppdelningen:** besvarad så, utan uttryckligt textstöd för
  luftabsorptionen.
- Med refraktion: `skarmeffekt_fritt_falt_db` och Δℓ fungerar; för brytande atmosfär ska delmodell 7 få S′, R′ ur
  `d7.korrigerad_kalla_och_mottagare(x_t, z_t, x_t, z_t, stralar.kil.vag_kalla_m, stralar.kil.vag_mottagare_m,
  stralar.vinklar.theta1_rad, stralar.vinklar.theta2_rad, stralar.vinkelandring_kalla_rad,
  stralar.vinkelandring_mottagare_rad)` – inte prövat här.
- `viktregel="tryckt"` och `uppat="exakt"` finns för att P-S ska kunna pröva alternativen mot facit.
- `fullt_koherent=True` är bara för prövning (ekv. 158 utan koherensfaktorer).

### Mot testfallen (informativt, inget facit)

## Iakttagelser om metoden (inga val)

1. **Skärmhöjd → 0 ger inte plan mark för mjuk mark.** När kilen plattas ut (β → π) blir kilytornas speglade stråle
   markreflexen, men med den reella Q_av (utan fas, och aldrig under −0,369). För hård mark stämmer gränsen (0,001 dB);
   för σ = 200 saknas markdippen (+12,2 dB vid 630 Hz i exemplet). Metoden lutar sig mot r_scr1 → 0 (ekv. 332). Före
   2018 (komplex Q ur impedans) var felet mindre; P-K1 har visat att inte heller den formen ger delmodell 1.
2. **Profilen börjar i källan**, så Fresnelzonen kring reflexpunkten på källsidan når vid låga frekvenser bakom
   profilens första punkt, och w_1t < 1 trots plan mark (testfall 71: 0,95–0,99 under 100 Hz; för h_s = 0,01 m ännu 0,98 vid 315 Hz). w_Q1 = w_1t² sänker
   då reflexen något. Det följer av ekv. (174) och (187); samma sak gäller delmodell 2.
3. Den tunna skärmens Q_av bestäms av de översta 2 dm (F·λ = 0,17 m), oberoende av frekvens.
4. T₁ som inte är konvex (P-T:s iakttagelse om fall 34 med h_s = 0,01 m) ger β ≤ π. `kildiffraktion` ger då
   `BullerFel` (β < π, eller β = π med θ_S + θ_R = π). Inte åtgärdat här; i de fallen är r_scr1 ≤ 0,65 och delmodellen
   kan inte räknas alls förrän någon bestämt vad en "kil" med β ≤ π ska vara.
5. Ekv. (163) normerar med R_SR. ΔL₄ kan därför vara > 0 dB vid låga frekvenser (fyra strålar i fas: upp till
   +12 dB minus skärmverkan).

- **Viktregeln (Tolkningar 1–2).** Jag avviker från den normativa textens ekv. (187) till förmån för bakgrundsrapporten.
  Skälet (diskontinuitet i w_t = 1) är starkt, men vilken formel som avsågs 2014 vet jag inte; uttrycket återkommer
  likadant i delmodell 5 och 6, så det är inget enstaka sättfel. P-5 och P-6 får samma fråga.
- **Ekv. (301)** i skuggan: tecknet är mitt; AV 1851/00 täcker bara θ_S − θ_R < π.
- **Bilaga G:s geometri (Tolkningar 5–6)** vilar på figur G.1. α ≥ π/2 och α ≤ 0 är bara prövade mot min egen läsning.
- **Ramen i ekv. (161) (Tolkningar 10)** avviker från bokstaven på lutande baslinje (millimeter till centimeter i R_S).
- Refraktionen i skärmdelen är bara prövad genom gränsvärde, tecken och riktning, inte mot ett känt svar. Läget
  `uppat` ärver P-R1:s öppna fråga.
- Jämförelsen mot dL bygger på samma obelagda antaganden som i B4 (en källhöjd i taget, cos θ) plus s_u = 0 och
  r_scr1 = 1. Att 0,01 m-kurvan träffar inom 0,1–0,2 dB i 50–250 Hz kan delvis vara tur; över 400 Hz går det inte att
  säga mer än att testvärdet ligger mellan kurvorna.
- Ingen prövning finns mot ett känt svar för skärm på mark med ändlig impedans; där är bara reciprocitet,
  kontinuitet, invarians vid uppdelning och gränsfall prövade.
